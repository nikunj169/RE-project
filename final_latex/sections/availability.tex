\section*{Data Availability}
The observational data analyzed in this study were obtained from the Global Ocean Data Analysis Project version 2 (GLODAP v2.2023) public data repository (\url{https://www.glodap.info/}). The post-processed analytical datasets and evaluation splits are archived within the project repository.

\section*{Code Availability}
All source code, PySR configuration files, model fitting routines, spatial/cruise validation scripts, dependence-aware inference notebooks, and figure/table generation pipelines are open-source and available in the project repository. Complete execution environments are documented in \texttt{environment/environment.yaml}.
